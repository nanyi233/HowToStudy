# HowToStudy Skill

> **基于马斯克第一性原理的高效学习框架技能**

一个将「保留10%，删除90%」学习理念转化为可执行AI技能的工具。

---

## 🎯 技能概述

这个技能将复杂的学习方法论简化为可执行的五步工作流：

1. **质疑需求** - 验证学习需求的真实性
2. **定义目标** - 转化为可验证的具体目标  
3. **制定任务** - 分解为每日可执行任务
4. **查询路径** - 提供卡住时的高效解决路径
5. **反馈验证** - 用三要素验证学习成果

## 🔧 核心功能

### 五步工作流
- **需求验证**: 区分真实需求与焦虑
- **目标定义**: 转化为可验证目标
- **任务分解**: 制定每日可执行任务
- **问题解决**: 提供高效查询路径
- **成果验证**: 三要素验证学习效果

### 反模式识别
- 识别并纠正过度方法论化
- 避免工具负担和过程指标崇拜
- 建立正确的反馈机制

### 实践案例库
- AI工具开发案例
- 技术面试准备案例
- 项目学习案例

## 🎪 实践建议

### 初学者
1. 从一个小项目开始
2. 关注「能跑」这个最低标准
3. 逐步增加复杂度

### 进阶者
1. 挑战更复杂的项目
2. 注重「能讲清楚」和「能被用」
3. 建立个人知识体系

### 教学者
1. 用这个框架设计课程
2. 强调结果导向
3. 提供及时的实践反馈

## ⚠️ 注意事项

### 适用场景
- 技术技能学习
- 项目驱动学习
- 结果导向学习
- 克服学习焦虑

### 不适用场景
- 需要大量记忆的知识（如语言学习）
- 理论研究型学习
- 艺术创作类学习

### 使用限制
- 需要用户有基本的学习动力
- 适合有一定自学能力的学习者
- 需要配合具体的学习资源
